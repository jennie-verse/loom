# Loom 사용 안내

## 설치

Loom은 인터넷 없이도 동작하도록 만든 PWA(Progressive Web App)입니다. 처음 한 번은 온라인 상태에서 배포 주소를 열고, iPhone Safari에서 공유(Share) → 홈 화면에 추가(Add to Home Screen)로 설치하세요. 설치한 홈 화면 앱을 주 사용 환경으로 삼으면 Safari 탭보다 저장소가 안정적으로 유지됩니다.

이 앱은 **iPhone 세로 화면 전용**입니다. 가로로 돌려도 화면이 깨지지는 않지만, 가로 전용 레이아웃은 따로 없습니다.

## 기본 화면 (Day)

- 상단 헤더: `◀`/`▶`로 하루씩 이동, 날짜를 탭하면 월 달력이 열립니다. 오른쪽에는 오늘의 완료 수/전체 수 · 계획된 총 시간이 표시됩니다. `Today` 버튼은 오늘로 이동하면서 현재 시각으로 스크롤합니다.
- Now & Next 줄: 지금 진행 중인 일과 남은 시간, 다음 일정을 보여줍니다. 오늘이 아닌 날짜에서는 그 날의 블록 수·총 시간 요약으로 바뀝니다.
- 시간축: 00시부터 24시까지 전부 보입니다. 이른 새벽(00–06시)에 블록이 없으면 얇게 접혀 있으며, 탭하면 펼쳐집니다.
- 진한 로즈색 가로선이 현재 시각입니다 (오늘 날짜에서만 보임).

## 블록 다루기

| 동작 | 결과 |
|---|---|
| 빈 시간대 탭 | 그 시각에 새 블록 만들기 |
| 블록 탭 | 편집 시트 열기 |
| 블록을 길게 눌러 드래그 | 시간 이동 |
| 블록 아래쪽 가장자리를 드래그 | 길이 조절 |
| 블록을 길게 눌렀다가 그대로 손 떼기 | Duplicate(복제) · Delete(삭제) 메뉴 |
| 좌우로 스와이프 | 이전 날 / 다음 날 |
| 완료 체크 영역 탭 | 완료 표시 켜고 끄기 |

블록에는 제목, 부제목, 한 줄 메모가 있으면 블록 높이가 허락하는 만큼 표시됩니다. **상세 메모**는 블록에 직접 보이지 않고, 오른쪽 위 작은 점으로만 표시되며 탭해서 열어야 볼 수 있습니다.

같은 시간대에 블록이 겹치면 좌우로 나란히 표시됩니다. 4개 이상 겹치면 처음 3개만 보이고 `+N`을 탭하면 나머지를 포함한 전체 목록이 작은 시트로 열립니다.

## 키보드로만 조작하기

드래그 없이도 모든 조작이 가능합니다. `Tab`으로 블록을 시작 시각 순서대로 이동한 뒤:

- `Enter` / `Space`: 편집 시트 열기
- `↑` / `↓`: 시간 이동
- `Shift` + `↑` / `↓`: 길이 조절
- `Delete` / `Backspace`: 삭제 (Undo 가능)
- `Esc`: 시트·메뉴 닫기

## Agenda 화면

하단 `Agenda` 버튼을 누르면 목록 화면으로 바뀝니다. 블록이 아무리 짧아도 제목·부제목·메모가 항상 전부 보입니다. 완료 체크, 편집, 복제, 삭제를 목록에서 바로 할 수 있습니다.

## 템플릿

하단 `More` → `Templates`에서 Weekday(평일) / Weekend(주말) 기본 템플릿과 직접 만든 템플릿을 관리합니다. 블록이 비어 있는 템플릿은 먼저 채워야 적용할 수 있습니다. 적용할 때는 세 가지 중 고릅니다:

- **Add**: 오늘 블록은 그대로 두고 템플릿 블록을 추가
- **Fill gaps**: 비어 있는 시간에만 채우고, 겹치는 자리는 건너뜀
- **Replace**: 오늘 블록을 전부 지우고 템플릿으로 교체 (5초 안에 Undo 가능)

`Save today as template`으로 오늘의 배치를 새 템플릿으로 저장할 수 있습니다 (날짜와 완료 상태는 저장되지 않습니다).

## 설정

`More` → `Settings`에서 글자 크기 6단계(6~17px), 시간 간격 5단계(48~120px), 스냅 단위 4단계(5~30분), 기본 스크롤 시각, 심야 접기, 한 주 시작 요일을 바꿀 수 있습니다. 시간 간격을 좁게 설정하면 짧은 블록의 메모가 가려질 수 있다는 안내가 화면에 함께 표시됩니다.

백업·복원, 오래된 데이터 삭제, 전체 초기화는 [백업·복원 안내](BACKUP-RESTORE-KO.md)를 확인하세요. 캐시나 업데이트 문제는 [문제 해결 안내](TROUBLESHOOTING-KO.md)를 확인하세요.
