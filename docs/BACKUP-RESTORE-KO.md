# Loom 백업·복원 안내

Loom의 블록·템플릿은 이 기기의 IndexedDB에만 저장됩니다. 클라우드 자동 동기화는 없으므로, 정기적으로 JSON으로 내보내 iCloud Drive 등 앱 밖의 안전한 곳에 보관하세요. 마지막 백업으로부터 30일이 지나면 헤더 아래에 안내 줄이 나타납니다.

## 내보내기 (Export)

1. 하단 `More` → `Settings` (또는 `More` → `Export JSON`)를 엽니다.
2. `Export JSON`을 누르면 `loom-backup-YYYY-MM-DD.json` 파일이 만들어지고 공유 시트가 열립니다.
3. 저장 위치로 **iCloud Drive**를 선택하면 다른 기기에서도 열어볼 수 있습니다.

파일 안에는 모든 블록과 템플릿이 들어 있습니다. 설정(글자 크기 등)은 포함되지 않습니다 — 기기별로 원하는 화면 밀도가 다를 수 있기 때문입니다.

## 가져오기 (Import)

1. `More` → `Import JSON`에서 백업 파일을 선택합니다.
2. 파일 형식이 `{ "format": "loom-backup" }`이 아니면 이유와 함께 거부됩니다. 다른 앱의 JSON은 가져올 수 없습니다.
3. 가져오는 방식을 고릅니다.
   - **Merge**: 기존 데이터를 유지한 채 합칩니다. 같은 `id`가 있으면 더 최근에 수정된(`updatedAt`) 쪽이 남고, 결과는 `추가 n · 갱신 m · 건너뜀 k`로 안내됩니다.
   - **Replace all**: 이 기기의 모든 블록과 템플릿을 파일 내용으로 완전히 바꿉니다. 확인을 거치며, 적용 후 5초 안에 Undo로 되돌릴 수 있습니다.

## 오래된 데이터 정리

`Settings` → `Delete data before…`에서 날짜를 고르면 그 이전 블록이 모두 삭제됩니다. 확인 절차를 거칩니다. 되돌릴 수 없으니 먼저 백업하는 것을 권합니다.

## 전체 초기화

`Settings` → `Reset everything`은 이 기기의 모든 블록·템플릿·설정을 지웁니다. 되돌릴 수 없습니다. 실행 전 반드시 Export로 백업하세요.

## 데이터가 사라진 것처럼 보일 때

앱을 오래 쓰지 않으면 iOS Safari가 저장 공간을 정리할 수 있습니다. Loom은 첫 저장 시 `navigator.storage.persist()`로 보존을 요청하지만 보장되지는 않습니다. 앱이 "데이터가 있었는데 지금은 비어 있다"는 안내를 보여주면 최근 백업 파일을 Import로 복원하세요.
