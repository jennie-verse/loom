# Loom 문제 해결 안내

## 화면이 옛날 버전 그대로 보여요

Loom은 Service Worker로 파일을 캐시해 오프라인에서 동작합니다. 새 버전을 배포한 뒤에도 이미 설치된 앱은 캐시된 옛 버전을 계속 보여줄 수 있습니다.

1. 앱을 열어둔 채 잠시 기다리면 하단에 `New version available` 토스트가 뜹니다. `Reload`를 누르면 새 버전이 적용됩니다.
2. 토스트가 뜨지 않으면 앱을 완전히 종료했다가 다시 열어보세요.
3. 그래도 안 바뀌면 홈 화면 앱을 삭제하고 Safari에서 주소를 다시 열어 재설치하세요. **재설치 전에 반드시 Export로 백업하세요** — 데이터는 IndexedDB에 남아있지만, 만약을 대비하는 편이 안전합니다.

## 데이터가 안 보여요 / 사라진 것 같아요

- 먼저 같은 브라우저·같은 앱(홈 화면 앱 vs Safari 탭)으로 열었는지 확인하세요. 홈 화면 앱과 Safari 탭은 저장소가 분리될 수 있습니다.
- 헤더 아래에 "Storage looks empty but data was expected" 안내가 보이면, 최근 백업 파일을 `Settings → Import JSON`으로 복원하세요.
- "Storage unavailable" 화면이 보이면 이 기기의 IndexedDB를 열 수 없는 상태입니다. `Retry`로 다시 시도하고, 계속되면 `Export diagnostics`로 진단 정보를 저장한 뒤 다시 설치해보세요. 데이터는 지워지지 않았을 가능성이 높지만 이 화면에서는 새 블록을 저장할 수 없습니다.

## 앱이 인터넷 없이 안 열려요

한 번은 온라인 상태로 열어야 Service Worker가 파일을 캐시합니다. 그 이후부터 오프라인에서 열립니다. 브라우저 저장 공간이 부족해 캐시가 지워졌다면 다시 온라인으로 한 번 열어주세요.

## 글자가 Verdana로 보여요 (Lexend가 아닌 것 같아요)

Lexend 폰트 파일(`assets/fonts/`)이 없거나 손상되면 자동으로 Verdana로 대체됩니다. 화면과 기능은 정상 동작하지만, 원래 폰트로 보이길 원한다면 `assets/fonts/lexend-400.woff2`, `lexend-700.woff2` 파일이 저장소에 정상적으로 올라갔는지 확인하세요.

## 시간 간격을 좁게 했더니 메모가 안 보여요

의도된 동작입니다. `Settings`의 시간 간격을 좁게(48px 등) 설정하면 짧은 블록은 제목만 보이는 Micro 단계로 내려갑니다. 메모까지 보고 싶다면 시간 간격을 넓히거나, 언제든지 전체가 다 보이는 `Agenda` 화면을 사용하세요.

## 그 밖의 문제

브라우저 개발자 도구의 Console 탭에서 오류 메시지를 확인하세요. 오류가 특정 조작(드래그, 가져오기 등) 직후에만 나타난다면 그 조작 이름과 오류 메시지를 함께 기록해두면 원인을 찾기 쉽습니다.
